# CanvasPro 用户体验优化计划

> 版本：v1.0 ｜ 创建：2026-08-24 ｜ 状态：批次 A/B 执行中，C/D 已规划待排期
>
> 来源：三轮系统走查（代码级审查 → 用户旅程分析 → 真实用户模拟），
> 合并去重后约 40 个优化点，按「用户可感知价值优先、技术项降级暂缓」原则组织。

---

## 一、原则

1. **用户可感知 > 技术完善**：能被用户看见、感受到的改进优先；纯工程项归入暂缓清单
2. **痛点排序**：按"用户痛感"而非实现难度排序——丢数据 > 打不了中文 > 学不会 > 不好用 > 不能用手机
3. **每批次可独立交付**：批次结束即 typecheck + test + build + 手动过检 + 提交

## 二、用户画像与痛点地图

| 画像 | 描述 | 核心痛点 | 对应批次 |
|------|------|----------|----------|
| 小王（创业新手） | 不懂画布，第一次用 | 区块不知道填什么；被教程挡住；输入法选词误提交 | B / A |
| 老李（效率型） | 用过 Miro/Canvanizer | 无撤销、无双击创建、无右键、无多选——"肌肉记忆三件套"缺失 | A / C |

## 四、批次 A：安全感与中文体验（P0）

### A1 撤销 / 重做（Ctrl+Z / Ctrl+Y）
- **现象**：误删便利贴无法找回；PRD 标注 P1 一直未实现
- **用户影响**：编辑器类产品最大的安全感缺口；效率型用户会因此直接流失
- **方案**：canvas store 内快照栈——每次变更前深拷贝 `{notes, blocks}` 入栈，**每改一次存一步，50 步上限**（不做输入合并，便利贴场景短文本居多）；切换/新建/删除画布时清空栈；工具栏增加撤销/重做按钮（可发现性）
- **涉及**：`stores/canvas.ts`、`components/toolbar/Toolbar.vue`、`useKeyboardShortcuts.ts`
- **验收**：增删改/拖拽/改色/锁定/快照恢复均可 Ctrl+Z 回退、Ctrl+Y 重做；刷新后栈清空（可接受）；单元测试覆盖

### A2 危险操作防护
- **现象**：删除画布无确认；恢复快照直接覆盖且不可回退；导入 JSON 无预览直接生效
- **方案**：
  - 删除画布 → 确认对话框（显示画布名与便利贴数）
  - 恢复快照 → 自动创建「恢复前」备份快照（持久化，与 A1 内存栈互补）+ 确认提示
  - 导入 JSON → 解析后预览（名称/便利贴数/模板）再确认
- **涉及**：新增 `ConfirmDialog.vue`；`CanvasSwitcher.vue`、`SnapshotsPanel.vue`、`stores/canvas.ts`
- **验收**：三个入口均有防护；确认弹窗为应用内样式（非浏览器原生）

### A3 Toast 通知系统
- **现象**：导入失败用原生 alert；导出成功无任何反馈；存储写入失败静默
- **方案**：`useToast` composable + 全局 `AppToast.vue`（aria-live="polite"，3s 自动消失，成功/错误两态）；替换所有 alert；导出完成、快照创建、保存成功、存储失败（30s 节流）均出 toast
- **涉及**：新增 `composables/useToast.ts`、`components/ui/AppToast.vue`；`ExportDialog.vue`、`CanvasSwitcher.vue`、`useLocalStorage.ts`
- **验收**：全应用无 alert()；导出/快照/保存均有可见反馈

### A4 中文输入法（IME）兼容 ⚠️ 高频硬伤
- **现象**：内容框按 Enter 提交——中文输入法选词的 Enter 也触发提交，每打一个词被强制退出编辑
- **方案**：StickyNote 标题/内容监听 `compositionstart/end`，组合输入期间忽略 Enter/Escape
- **涉及**：`StickyNote.vue`
- **验收**：中文选词 Enter 不提交；正常 Enter 提交；Esc 在组合期间不取消编辑

### A5 画布不存在 404 态 + 错误边界
- **现象**：访问失效的 /canvas/:id 静默显示空白/旧画布；任何组件抛错整站白屏
- **方案**：编辑器检测路由 id 不存在于画布列表 → 显示"画布不存在"页（返回首页/新建画布）；App.vue 挂 onErrorCaptured 错误边界，兜底 UI + 重新加载按钮
- **涉及**：`CanvasEditorView.vue`、`App.vue`（新增 `ErrorBoundary.vue`）
- **验收**：伪造失效 id 显示 404 态；人为抛错显示兜底而非白屏

### A6 PWA 更新改为用户确认
- **现象**：autoUpdate 静默刷新，可能打断编辑中的用户
- **方案**：`registerType: 'prompt'`；`onNeedRefresh` 时顶部出现"发现新版本"条，用户点击才刷新
- **涉及**：`vite.config.ts`、`main.ts`、新增 `pwa.ts` 桥接 + `UpdateBanner.vue`
- **验收**：发新版本后旧页面出现提示条，点击前不刷新

### A7 数据版本号（数据资产保护）
- **现象**：localStorage 数据无 schemaVersion，导出 JSON 无 version 字段（PRD 4.4 要求）；未来格式变更会静默损坏用户数据
- **方案**：localStorage 存储包装为 `{ version: 1, canvases }`（读取兼容旧数组格式）；导出 JSON 注入 `version` 与 `exportedAt`；导入时校验
- **涉及**：`stores/canvas.ts`、`utils/export.ts`
- **验收**：旧格式数据可正常迁移读取；新导出文件含版本字段；单测覆盖

## 五、批次 B：上手引导与价值传达（P1）

### B1 区块提示文案（教学核心）
- **现象**：新手分不清「关键合作」与「关键业务」；画布只有骨架没有教学
- **方案**：`CanvasBlock` 增加 `hint` 字段，为 3 个模板全部 22 个区块撰写"该填什么"引导文案；BlockHeader 显示 Info 图标，悬停展示
- **验收**：每个区块可悬停查看说明；文案覆盖"是什么 + 举例"

### B2 空画布中央引导
- **现象**：新建画布一片空白，用户不知道从哪开始
- **方案**：画布无便利贴时中央浮层：「从一张便利贴开始」+ [添加第一张] [载入示例看看]；便利贴 placeholder 改为引导性文案
- **验收**：空画布可见引导；添加后消失

### B3 新建便利贴自动聚焦（修复 AC-04 实际未达成）
- **现象**：+ 按钮/N 键创建后仅选中，未进入编辑态（验收文档误标 ✅）
- **方案**：store 记录 `pendingEditNoteId`，StickyNote 挂载时检测并自动进入编辑
- **验收**：三种创建方式（+/虚线区/N）均自动聚焦标题

### B4 编辑器内一键载入示例
- **现象**：用户想"看看填好的样子"需退出→案例库→复制，四步
- **方案**：案例数据抽取至 `src/data/examples.ts`；空画布引导按钮一键填充 Uber 案例内容到当前画布（走 undo 栈，可撤销）
- **验收**：空画布一键载入；Ctrl+Z 可完全撤销

### B5 首页价值传达重写
- **现象**："复刻 Canvanizer"对新用户无意义；本地免注册卖点未传达；成品展示缺失
- **方案**：Hero 改为"把创业想法，理成一张清晰的商业模式图"+ 徽章行（免注册/数据仅存本地/离线可用/免费）；Hero 示意图替换为真实 Uber 案例内容渲染；CTA「开始创作」直接进编辑器
- **验收**：首屏无 Canvanizer 字样；可见真实内容示例与卖点徽章

### B6 教程完成回模板选择
- **现象**：教程结束硬编码进商业画布，用户没得选
- **方案**：完成/跳过教程 → 返回首页模板区选择
- **验收**：教程完成后落在首页

### B7 专业感细节
- **现象**：多标签页标题相同无法区分；CJK 字体栈缺失；Ctrl+P 打印出一堆按钮
- **方案**：document.title 跟随画布名（编辑器）/页面名；body 字体栈补 PingFang SC / Microsoft YaHei / Noto Sans SC；打印样式隐藏工具栏导航、画布满幅
- **验收**：切换画布标题变化；Windows 下中文渲染明确；Ctrl+P 输出干净画布
