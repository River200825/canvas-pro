# CanvasPro 用户手册

## 快速上手

1. 打开首页，从「选择模板开始」点击任意模板卡片，或点击 Hero 区「开始创作」
2. 首次使用会自动进入交互教程（含可动手的练习沙盒），可随时跳过；教程结束后回到首页自选模板
3. 空画布中央有引导：「添加第一张」或「载入示例」看看 Uber 案例是怎么填的
4. 顶部导航「我的画布」可一键回到最近编辑的画布

## 撤销与重做

- `Ctrl+Z` 撤销上一步操作（删除、移动、改色、编辑、快照恢复等均可撤销）
- `Ctrl+Y` 或 `Ctrl+Shift+Z` 重做
- 最多保留 50 步；切换/新建画布后清空
- 工具栏也有 ↶ 撤销 / ↷ 重做按钮

## 安全保护

| 操作 | 保护机制 |
|------|----------|
| 删除画布 | 弹窗确认，显示将删除的内容概要 |
| 恢复快照 | 恢复前自动创建「恢复前」备份快照，随时找回 |
| 导入 JSON | 先预览名称/便利贴数，确认后才导入为新画布 |
| 本地存储写满 | 顶部提示导出备份，不会静默丢数据 |

## AI 功能

CanvasPro 支持 AI 生成画布草稿与 AI 打磨便签（需自备 API Key）：

**首次使用**：点击工具栏 ✨「AI」→「AI 设置」，填入 OpenAI 兼容接口地址、API Key 与模型名（支持 OpenAI / DeepSeek / 月之暗面 / 各类中转），可点击「测试连接」验证。Key 仅保存在本地浏览器，请求由你的浏览器直连服务商，本应用不经手任何数据。

**AI 生成草稿**：点击工具栏 ✨ 或空画布引导中的「AI 生成」，用一句话描述创业想法（如"面向独居养猫人群的上门喂猫平台"），AI 将为每个区块生成 1-3 张便签草稿追加到画布，Ctrl+Z 可整体撤销。

**AI 打磨便签**：右键任意便签 →「AI 打磨...」，选择预设指令（润色 / 更具体 / 挑战假设 / 精简）或输入自定义指令，改写结果可编辑后一键替换。

## 画布编辑

### 创建便利贴
- **双击区块内空白处**（最快方式）
- 点击区块右上角 **+** 按钮
- 点击区块内空白虚线区域
- 快捷键 `N`（在第一个区块创建）
- 创建后会**自动聚焦标题**，直接打字即可

### 不知道区块该填什么？
每个区块标题旁有 ℹ️ 图标，悬停即可查看该区块的填写说明与示例。

### 编辑便利贴
- 单击标题或内容区域直接输入
- `Enter` 提交，`Esc` 取消
- 中文输入法选词时的 Enter 不会误提交

### 便利贴操作
选中便利贴后操作按钮**常驻显示**（悬停其他便利贴也会显示）：

| 按钮 | 功能 |
|------|------|
| ✏️ | 编辑 |
| 🎨 | 更改颜色（7 色） |
| 🔒 | 锁定 / 解锁（锁定后禁止拖拽、编辑、删除） |
| ⧉ | 复制一份 |
| 🗑 | 删除 |

也可以**右键点击**便利贴打开菜单：改色 / 编辑 / 复制 / 锁定 / 删除。

### 多选与批量操作
- `Ctrl` / `Cmd` + 点击：多选 / 取消多选
- `Shift` + 点击：同区块内范围多选
- 选中 2 张以上时底部出现批量工具条：**改色 / 移动到区块 / 复制 / 删除**
- `Esc` 取消全部选择；批量操作整体算一步，`Ctrl+Z` 可整体撤销

### 移动便利贴
直接按住便利贴拖到目标区块（鼠标与触屏均支持），松手后自动归属新区块并排在末尾；目标区块会高亮提示。

## 移动端

| 手势 | 效果 |
|------|------|
| 单指拖拽空白处 | 平移画布 |
| 双指捏合 | 以两指中心缩放（25%~300%） |
| 单指双击空白处 | 重置视图 |
| 按住便利贴拖动 | 移动到其他区块（横向拖动；竖向滑动仍为滚动列表） |
| 双击区块空白处 | 创建便利贴 |

小屏（<640px）工具栏自动收纳次要操作到「⋯」菜单。

## 视野控制

| 操作 | 效果 |
|------|------|
| `Ctrl` + 滚轮 | 以鼠标为中心缩放（25%~300%） |
| 空白处拖拽 | 平移画布 |
| 按住 `空格` + 拖拽 | 从任意位置（含便利贴上）平移 |
| 双击空白处 | 重置视图到 100% |
| `Ctrl+0` / `Ctrl+=` / `Ctrl+-` | 重置 / 放大 / 缩小 |

## 多画布管理

点击工具栏左上角画布名称打开切换器：

- **新建画布**：`Ctrl+Shift+N`
- **导入 JSON**：选择之前导出的备份文件
- **重命名 / 复制 / 删除**：悬停画布条目显示操作按钮（复制 `Ctrl+Shift+D`）

## 快照版本控制

- 手动创建：工具栏时钟图标打开快照面板 → 「创建快照」，或 `Ctrl+S`
- 自动创建：每 30 分钟一次
- 最多保留 20 个，超出自动移除最旧的
- 点击 ↺ 恢复到该时刻，🗑 删除快照

## 导出与备份

工具栏「导出」按钮或 `Ctrl+E` 打开导出对话框：

| 格式 | 说明 |
|------|------|
| PNG | 1x/2x/3x 倍率可选，可勾选透明背景 |
| PDF | A4/A3、横/纵向；内容自动分页；页眉含画布名与时间，页脚含页码；中文以高清图像嵌入 |
| Markdown | 按区块结构化，便于粘贴到 Notion / 语雀 |
| JSON | 完整数据备份，可通过切换器「导入 JSON」恢复 |

## 演示模式

- 按 `F` 或点击工具栏全屏图标进入：隐藏所有 UI，仅展示画布
- `←` / `→` 切换上一张 / 下一张画布
- `Esc` 或右上角按钮退出

## 主题

点击工具栏 / 首页导航的主题按钮，在 **浅色 → 深色 → 跟随系统** 间循环切换，偏好自动保存。

## 常见问题

**数据存在哪里？会丢失吗？**
数据保存在浏览器 localStorage，不联网不上传。清除浏览器数据会删除画布，重要画布请定期导出 JSON 备份。

**PDF 里的文字可以选中吗？**
中文内容以高清晰度图像嵌入（与 Canvanizer 免费版行为一致），页眉页脚元信息为矢量文字。

**如何迁移到另一台电脑？**
导出 JSON → 在新设备的切换器中选择「导入 JSON」。
