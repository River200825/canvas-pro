# CanvasPro 用户手册

## 快速上手

1. 打开首页，从「选择模板开始」点击任意模板卡片，或点击 Hero 区「开始创作」
2. 首次使用会自动进入交互教程，可随时跳过；之后可在编辑器点击键盘图标重新查看
3. 顶部导航「我的画布」可一键回到最近编辑的画布

## 画布编辑

### 创建便利贴
- 点击区块右上角 **+** 按钮
- 点击区块内空白虚线区域
- 快捷键 `N`（在第一个区块创建）

### 编辑便利贴
- 单击标题或内容区域直接输入
- `Enter` 提交，`Esc` 取消
- 点击便利贴选中（蓝色描边），支持键盘删除与复制粘贴

### 便利贴操作
悬停便利贴右上角出现操作按钮：

| 按钮 | 功能 |
|------|------|
| 🎨 | 更改颜色（7 色） |
| 🔒 | 锁定 / 解锁（锁定后禁止拖拽、编辑、删除） |
| ⧉ | 复制一份 |
| 🗑 | 删除 |

### 移动便利贴
直接拖拽便利贴到目标区块，松手后自动归属新区块；目标区块会高亮提示。

## 视野控制

| 操作 | 效果 |
|------|------|
| `Ctrl` + 滚轮 | 以鼠标为中心缩放（25%~300%） |
| 空白处拖拽 | 平移画布 |
| 按住 `空格` + 拖拽 | 从任意位置（含便利贴上）平移 |
| 双击空白处 | 重置视图到 100% |
| `Ctrl+0` / `Ctrl+=` / `Ctrl+-` | 重置 / 放大 / 缩小 |

## 多画布管理

点击工具栏左上角画布名称打开切换器：

- **新建画布**：`Ctrl+Shift+N`
- **导入 JSON**：选择之前导出的备份文件
- **重命名 / 复制 / 删除**：悬停画布条目显示操作按钮（复制 `Ctrl+Shift+D`）

## 快照版本控制

- 手动创建：工具栏时钟图标打开快照面板 → 「创建快照」，或 `Ctrl+S`
- 自动创建：每 30 分钟一次
- 最多保留 20 个，超出自动移除最旧的
- 点击 ↺ 恢复到该时刻，🗑 删除快照

## 导出与备份

工具栏「导出」按钮或 `Ctrl+E` 打开导出对话框：

| 格式 | 说明 |
|------|------|
| PNG | 1x/2x/3x 倍率可选，可勾选透明背景 |
| PDF | A4/A3、横/纵向；内容自动分页；页眉含画布名与时间，页脚含页码；中文以高清图像嵌入 |
| Markdown | 按区块结构化，便于粘贴到 Notion / 语雀 |
| JSON | 完整数据备份，可通过切换器「导入 JSON」恢复 |

## 演示模式

- 按 `F` 或点击工具栏全屏图标进入：隐藏所有 UI，仅展示画布
- `←` / `→` 切换上一张 / 下一张画布
- `Esc` 或右上角按钮退出

## 主题

点击工具栏 / 首页导航的主题按钮，在 **浅色 → 深色 → 跟随系统** 间循环切换，偏好自动保存。

## 完整快捷键表

编辑器内按 `?` 随时查看。

| 快捷键 | 功能 |
|--------|------|
| `N` | 新建便利贴 |
| `Delete` / `Backspace` | 删除选中便利贴 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴选中便利贴 |
| `Ctrl+S` | 创建快照 |
| `Ctrl+Shift+S` | 保存画布 |
| `Ctrl+E` | 打开导出对话框 |
| `Ctrl+Shift+N` | 新建画布 |
| `Ctrl+Shift+D` | 复制当前画布 |
| `F` | 切换演示模式 |
| `Ctrl+0` | 重置视图 |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小 |
| `空格` + 拖拽 | 平移画布 |
| `←` / `→` | 演示模式切换画布 |
| `?` | 快捷键帮助 |
| `Esc` | 关闭弹窗 / 退出演示 |

> 提示：在输入框中打字时，字母快捷键自动禁用。

## 常见问题

**数据存在哪里？会丢失吗？**
数据保存在浏览器 localStorage，不联网不上传。清除浏览器数据会删除画布，重要画布请定期导出 JSON 备份。

**PDF 里的文字可以选中吗？**
中文内容以高清晰度图像嵌入（与 Canvanizer 免费版行为一致），页眉页脚元信息为矢量文字。

**如何迁移到另一台电脑？**
导出 JSON → 在新设备的切换器中选择「导入 JSON」。
